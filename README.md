# Task 3 – SQL Basics Project

## Tools
MySQL / PostgreSQL / SQLite

## Steps
1. Import CSV into database table named 'sales'
2. Run filtering queries using WHERE
3. Use ORDER BY for sorting
4. Apply SUM, AVG, COUNT with GROUP BY
5. Use HAVING for grouped filtering
6. Export aggregated output to CSV

## Files Included
- queries_task3.sql → All SQL queries
- sales_summary.csv → Aggregated results
- README.md → Project explanation

## Outcome
This project demonstrates basic SQL skills required for a Data Analyst:
Filtering, Sorting, Aggregations, Reporting.
